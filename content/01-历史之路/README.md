# 01 · 历史之路 — Road to WebSockets

> HTTP 如何演进、AJAX/Comet 如何"硬造"实时、WebSocket 如何诞生。对应站点：/guides/road-to-websockets/。

## 学习目标

- [ ] 能讲清 HTTP/0.9 → 1.0 → 1.1 的关键演进（为什么 1.1 是里程碑）
- [ ] 理解 AJAX（轮询）与 Comet（长轮询 / HTTP 流）的工作原理与局限
- [ ] 理解 SSE（EventSource）与 HTTP 流的关系
- [ ] 能说出 HTTP 不适合实时的 3 个根本原因（可扩展性、乱序/丢消息、无双向流）

## 关键概念清单

- [ ] HTTP 无状态请求-响应模型
- [ ] 轮询（polling）、长轮询（long polling）
- [ ] HTTP 流 / chunked transfer encoding
- [ ] 2008 年 Michael Carter 与 Ian Hickson 提出 WebSocket 的背景
