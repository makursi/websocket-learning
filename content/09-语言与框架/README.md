# 09 · 语言与框架 — Languages & Frameworks

> 各语言/框架的 WebSocket 生态选型。对应站点：/guides/languages/*与 /guides/frameworks/*。

## 学习目标

- [ ] 掌握 JavaScript/Node（ws 库）的服务端写法
- [ ] 至少掌握一门后端语言的生态（Python websockets / Go Gorilla / Java Spring Boot…）
- [ ] 了解主流 Web 框架的 WebSocket 集成（React / Next.js / Express / FastAPI / Django / Spring Boot）
- [ ] 能按项目需求做语言/框架选型（性能、生态、维护活跃度）

## 关键概念清单

- [ ] ws（Node.js）与原生浏览器 WebSocket
- [ ] Python：websockets / Autobahn / FastAPI
- [ ] Go：Gorilla WebSocket
- [ ] Java：Tyrus / Jetty / Spring Boot
- [ ] C#：SignalR / WebSocketSharp
- [ ] Rust / PHP 生态（选读）
