# 07 · 应用场景 — Use Cases

> WebSocket 解决的真实问题。对应站点：/guides/use-cases/* 与 AI 相关文章。

## 学习目标

- [ ] 理解聊天应用的核心循环：广播 / 房间 / 加入离开 / 打字状态
- [ ] 理解 AI 流式输出的特殊性：增量 token 推送、客户端取消信号、工具调用
- [ ] 理解实时通知与仪表盘的"推送 + 增量更新"模式
- [ ] 了解协同编辑、游戏等更多场景对协议的要求
- [ ] 能对未来方向（websockets-and-ai、future-of-websockets）形成自己的观点

## 关键概念清单

- [ ] 广播（broadcast）与房间（room）
- [ ] token 流式传输、取消/中断信号、工具调用响应
- [ ] 增量更新 vs 全量刷新
- [ ] 出现/在场（presence）
