# 内容按学习路径组织，而非镜像站点 URL

项目以 websocket.org 为内容主体，但站点是参考文档取向（Guides / Comparisons / Reference / Tools / Resources / Standards），直接镜像其 URL 结构会把学习体验做成查字典。我们决定按**学习路径重构**为 11 个编号章节（00-总览 → 10-参考速查）：先建立直觉与历史，再攻协议核心，最后覆盖模式、安全、对比、用例与生态。

**取舍**：镜像结构的优势是交叉引用零成本（读者能按站点 URL 定位），但学习顺序不佳；重构的优势是递进清晰，代价是章节与站点页面的映射需要维护。折中：在 `docs/站点映射.md` 和各章 README 中保留 URL 映射表；参考速查类内容（关闭码、浏览器支持、头部）尽量保持与站点一致的组织，方便日后当速查手册用。
